# Crane Lift Calculator

繁體中文吊裝能力試算 MVP，適用汽車式吊車與全地形吊車的重量彙整與使用率比較。無資料庫、登入、外部 API、PDF 解析或內建載重表。

## 本機開發

使用 Node.js 22 或 24 與 npm：

```sh
npm ci
npm run dev
npm test
npm run build
```

## 計算與限制

- 重量單位為公噸 t（1 t = 1,000 kg），接受非負數及最多三位小數，每項上限 1,000,000 t。額定能力必須大於零。
- 總吊重 = 吊物 + 吊鉤 + 索具及吊梁 + 其他附加重量。以整數公斤加總。
- 能力使用率 = 總吊重 ÷ 使用者輸入額定能力 × 100%。以未四捨五入數值比較，顯示最多三位小數。
- 額定能力必須符合實際半徑、臂長、支腿配置、配重等條件；廠牌型號僅供識別，不可用標稱噸數替代。
- 使用者可記錄來源及作業條件並聲明自行確認。工具不獨立驗證，不顯示正式 PASS，也不進行風速、地耐力、吊索受力、動載或其他吊裝安全檢核。
- **試算結果，不得直接作為吊裝核准依據。**

「儲存草稿」將一份草稿保存在目前瀏覽器的 localStorage，key 為 `crane-lift-calculator:draft:v1`。再次儲存會更新該份草稿；按「開啟草稿」可重新載入並重設來源確認。未儲存的輸入不會自動保存。清除網站資料或改用其他裝置／瀏覽器無法取回，私人瀏覽模式可能無法保存。不應視為正式紀錄或備份。

現有 PDF 僅保留於儲存庫，應用程式不讀取、不引用其內容。

## 人工驗收

1. 輸入吊物 10、吊鉤 0.5、索具及吊梁 0.3、其他 0.2，額定能力 20：總重 11 t，使用率 55%。
2. 額定能力改為 5：顯示 220% 與超出額定能力。
3. 額定能力為 0、留白或負值：結果不顯示數值，提示修正輸入。
4. 填寫來源、條件並確認後，修改任一額定能力／來源／條件應取消確認。
5. 儲存、重新整理後按開啟草稿，確認輸入恢復，來源確認已取消。
6. 在窄螢幕及鍵盤操作下檢查欄位、按鈕與提示。
